## Логика и регрессии

**256/256 тестов прошли**: `tests/mcp/*.test.mjs`, проверки фоновой навигации,
переноса/восстановления выбора Spaces и `tests/space-routing/*.test.mjs`.
Workspace — 33, media — 19, site tools — 34, восстановление папок — 6 отдельных
проверки в этой общей выборке. Производственные модули прошли ESLint с
конфигурацией Firefox и каноническими глобальными переменными Zen;
форматирование и проверка zen-browser skill также выполнены.

Нативные прогоны обнаружили и привели к отдельным исправлениям:

- Gecko CSP и привилегии worker: используется обычный module Worker с
  ограничением среды до вычисления выражения; бесконечная лямбда завершается
  родительским таймаутом.
- Фоновые вставки и завершение навигации сохраняют активную вкладку и Space;
  порядок массива URL и индексы неактивного Space соответствуют сайдбару.
- Асинхронный beforeunload блокирует страницу с несохранёнными изменениями
  без модального диалога и позволяет закрыть чистые соседние вкладки.
- Перенос сохраняет опустевшее окно; независимые окна сохраняют каноническое
  состояние закреплений без обязательного `gZenWindowSync`.
- Новые выгруженные вкладки нативной live folder наследуют Space от папки,
  даже пока на самой вкладке ещё нет соответствующего атрибута.
- Восстановление проверяет реальный DOM-контейнер Space: SessionStore может
  вернуть правильный атрибут Space, оставив узел вкладки в другом разделе.
  Проверяется и последующий выбор/загрузка восстановленной lazy-вкладки.
- Undo не переподключает неизменённые папки и их вкладки. Межоконный перенос
  ждёт фактического удаления старого узла папки/группы: нативный `delete()`
  завершается раньше анимации, и немедленный Undo иначе мог наполнить узел,
  который позднее удалялся. Отложенное удаление покрыто регрессиями.
- Нативное `tabsAndSplitViews` читает внутренний `groupContainer` Zen;
  внешний узел группы содержит её оболочку. Исправление позволяет нативному
  межоконному adoption получать настоящие вкладки обычной группы.
- Служебная пустая вкладка новой папки сохраняет её Space. При восстановлении
  старых папок без этого атрибута реальное размещение корневой папки сверяется
  с сохранённым Space и соседним элементом; вложенные папки остаются внутри
  родителя. Сохранённый порядок применяется и к папкам, уже находящимся в
  правильном Space; декоративные и вложенные разделители не служат якорями
  для корневого размещения.

## Границы проверки

- Подключён один физический Color LCD. Размещение на нём проверено реально;
  второй монитор, смена физической топологии, Linux и Windows не проверены.
  Отрицательные координаты и масштабирование нескольких экранов покрыты
  логическими тестами.
- Gecko может откладывать media playback и таймеры страницы, ни разу не
  выбранной пользователем. Медиа-сценарии сначала выбирают свою тестовую
  вкладку; новое API не обходит нативную политику воспроизведения.
- WebMCP экспериментальный: текущий Firefox реализует `navigator.modelContext`.
  Нативная отмена уже переданного callback и атомарная фиксация версии callback
  отсутствуют. После таймаута результат может быть неизвестен; проверяется
  поздняя квитанция без повторного запуска.
- Снимки восстановления закрытых вкладок находятся только в памяти клиента,
  ограничены 30 минутами, 32 операциями и 32 MiB. Они не переживают restart
  сервера или явный disconnect; долговременные подборки/правила сохраняются
  отдельно.
- Enpass: проверяется фактический ответ настоящего приложения через свежее
  расширение. Разблокировка хранилища и autofill не заявляются. Для Keepa
  выполнено локальное согласие на functional cookies; CAPTCHA, вход в сервис
  и пользовательский сценарий Keepa не проверялись.
- Включённый MCP предоставляет уже согласованный системный JS. Этот набор
  возможностей не меняет существующую модель доступа сервера. Кандидат не
  устанавливает новый skill в личную конфигурацию агента автоматически.
